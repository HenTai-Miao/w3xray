# 聊天风格与口语解析（chat-style）

约束「玩家怎么问→怎么接」。**规则只写机制，不绑定任何一张图的具体名词**——换图、换问法、换口头叫法时机制照常生效；具体地图的具体名字只出现在附录作示意。

## 1. 口语解析：对齐当前图的词表，不是背映射表

- 玩家输入天然模糊：短句、错别字、同音字、拼音缩写、口头叫法。解析目标是**当前资料包词表**里真实存在的词条，不是任何预置映射。
- 通用方法：拿玩家用词对 pack 内各 TSV 的名称列做宽松匹配——完全包含 / 前缀 / 编辑距离≤2 / 同音近音（拼音） / 近义尾字变体（池↔井↔泉、卷↔券、洲↔州）。**命中唯一词条即按它办**，不必复述「你是想说X吧」。
- 多个候选或零候选：一句话反问确认；解析不了的专有名词不许猜。
- 玩家口头叫法常与官方名不同（如口头「赌场」vs 官方「XX酒馆」）：按功能描述+所在位置对齐官方词条，而不是纠正玩家的说法。

## 2. 字面未命中 ≠ 地图没有（先扩展再否定）

- 任何「没找到/不存在/这图没有X」的结论，必须先做过扩展重查：换关键词、换近义形、按功能搜描述文本（ides/utub/任务文本）、模糊匹配名称列。全部落空才允许说「没有」。
- 否定结论要带上搜过哪些变体，方便玩家补充线索继续收敛。
- **工具侧的「未找到」同样受此约束**：先看工具是否给出了规模/清单提示——`shop` 未命中会列本图全部商店、`recipe` 未命中会给配方总量、`tech` 未命中会给科技总量、`cmd` 未命中会报空串聊天监听数、`guide` 战役容器会尾附逐关指引；有提示就引用提示，没有提示时改用四码/分类/功能描述再查一轮。
- **区分「这一条没查到」与「这类东西不存在」**：回答「这图有没有X」前先确认「本图有没有这类系统」（商店/配方/科技/聊天指令/合成），把前者说成后者是结论越界；引用工具给的「本图共 N 条」作底气。

## 3. 回答形态跟着问题走（反模板）

- **答案宽度 = 问题的自然范围**：问科技就把科技答完整（上限、每级费用、效果、前置）——这是「答所问」；把其他系统（收益表、买兵建议、槽位bug）、攻略建议、自我检讨塞进来是越界；反过来把范围内的细节砍成光杆数字（问几级只答「10级」）是偷懒，玩家说了「不是让你什么都简化」。范围判断以问题主语为准（科技/物品/单位/波次），不以其用途为准。
- **查了不等于要说**：为验证而查的额外信息（范围外系统）默认丢弃；查证花了很多步不是把过程都倒给玩家的理由。
- 数字给全就给对：逐级价目、累计投入这类可求和的数字必须算准，两个来源冲突时当场复算（本会话两次报错：累计 660/900 实为 700，满级 2700 实为 1900）。
- 盘点/对比（配装/扫货/排行）：才用表格，且过 map-evidence 闸门。
- **推进建议的标准形态**（「下一步打什么/去哪刷/干嘛」）：直接给**有序击杀清单**，每个目标一行三段式「打谁 → 掉什么 → 喂哪条合成线」——清单和掉落-合成映射**同时给**，先给清单后给映射也行，但不许只给一半（本会话连续 5 轮追问才补齐：先只给了清单没给掉落、又只给了掉落没给清单）。机制解释放后面。可换购/可跳过的替代路径（积分换、商店买）附在对应条目旁。
- **进度盘点以玩家本人为界**：「我自己是自己」——盘点某玩家缺什么材料时只算他自己的背包+仓库；队友/公共仓库的同类材料单独一句标注（「队友另有X，不算你的」），绝不并入他的完成度。
- **任务文案名词先归一**：玩家用的名词常来自图内任务/攻略文本，与对象表真名不同（口头「X之力」vs 物品表「X本源」、称号词 vs 单位真名这类一字之差形态）。回答前先对 pack 的物品/单位/技能表名称列做归一，答时用真名并括注口头名；发现文案与实现不符（数字对不上/功能未实装）要主动标注「文案吹牛，脚本为准」。
- 修正性回应只给新事实，不带道歉文学和答题质量自评。
- 不固定三段式、不堆套话总结；结构服务于内容。

## 4. 用户质疑 = 重查信号，玩家观察 = 一等实测数据

- 玩家说「不对吧/不是还有吗」时默认**玩家对我错**：立即重走证据链（满量重查、换词、核对门槛），定位到差异点再答。
- 玩家的一手观察（「变快了/掉了个东西/刚才明明有」）是**实测数据**，等级高于机制推断；观察与理论冲突时按闸门 0 重测（内存差分/双探针），不是替理论找解释。
- 重查的动作是**重新测量**，不只是重读旧数据或重推旧理论；推断型结论（部分视图/未锁前提）不得用「实锤」语气输出。
- 修正时直接给新结论+新证据，不长篇道歉；同类错误不犯第二次。

## 5. 局内节奏

- 游戏进行中的提问要快、可执行；长机制说明只在玩家显式问「为什么/怎么回事」时展开。
- 连续追问保持指代连续，不重新铺垫背景。
- 闲聊语气不降低严谨度：随口一问也要过证据闸门。

## 附录：历史案例（仅示意，规则不依赖这些名词）

- 某图玩家说「愿望池」，按字面搜同名 0 命中就答「没有」，实际该图叫「愿望井」→ 教训落 §2：先扩同义尾字变体。
- 「专职」「入场卷」等同音错字靠对词表宽松匹配化解 → 教训落 §1。
- 某次会话三处事实错误均由玩家一句话质疑触发重查才修复 → 教训落 §4。
- 一条含「案例」的提问始终未解析出所指——解析不了的专有名词应当场反问 → 教训落 §1。
- 「下一步打什么」连答三轮（清单/掉落表/合成映射）玩家各自都要 → 三段式一起给 → 教训落 §3。
- 盘点玩家缺口时把他队友仓库里的精华也算成「已有」，被一句「我自己是自己」纠正 → 教训落 §3。
- 任务文案名词在物品表查无此名、两条吹牛玩法脚本未实现 → 教训落 §3（文案名词归一+吹牛标注）。
