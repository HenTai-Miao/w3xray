# 地图证据断言检查单（map-evidence）

回答玩家「怎么获得 X / 打谁掉 X / 一共有几个 X」之前，按顺序过完全部闸门。任何一闸不过，答案里必须写「未证实」而不是猜测补全。

## 闸门 0：玩家状态先行（先读人、再翻图、后开口；顺序不可倒置）

推进类问题（「接下来干嘛 / 怎么打 / 出什么装备 / 我该怎么变强」）的强制流程：

1. **先 live 重探现状**：选中英雄、背包六格、坐标、队友与资源（AGENTS.d/live.md 的强制重探同样适用）。
2. **对齐进度**：用坐标对齐地图区域/章节，用背包判断已拿到的档位，推断玩家当前进度点。
3. **差集推荐**：只推荐下一步「够得着」的升级——当前区域商店有售、当前等级能刷的掉落、原料已大半到手的配方；每件推荐物必须标注获取路径（哪家店/哪个 Boss/什么配方）。
4. **终局 BiS 只作附注**：S 级、满配套装等远期目标最多作为「路线图」一句带过，绝不作为主答案——玩家当前拿不到的成品不推。
5. **门槛核对**：推荐转职/挑战场/航线/副本前，先核对玩家等级与进度门槛（如 Reve>=N 航线、等级 19 转职、副本钥匙），不满足就先给「解锁这一步」的路径。
6. **满量才许排「最强」**：装备/商店大盘点必须满量枚举（闸门 2）后才允许下「最强/毕业」结论；盘点被截断过就明说「未覆盖全部」。

反例（灰色意志会话）：玩家问「我现在要干嘛」，正确路径是看位置（永远亭）+背包（已有荣誉套+陨石坠落）+进度（已通关）→ 答「二周目无尽深渊+刷符文池合星之守护」；错误路径是不看状态直接倒终局配装表。玩家原话：「你给我我也拿不到」「有时候你的逻辑并不是给我这个地图最好最强的装备，因为装备过多导致你自己都梳理的截断了」。

## 闸门 1：掉落断言前置（防「杀 NPC 掉神装」幻觉）

1. 先跑 `pack-query <pack> where <物品ID或名>` 和 `pack-query <pack> drop <物品ID或名>`，把输出贴进答案或引用行号。
2. 判定来源类型，只有这三类算证据：
   - `商店出售`（usei/Sellitems 货架行）
   - `掉落`/掉落表行（单位死亡掉落）
   - `脚本/触发奖励`（CreateItemLoc/UnitAddItemByIdSwapped/奖池 PlaceRandomItem）
3. 单位身上带着某物品 ≠ 会掉它。脚本在地图初始化里 `UnitAddItemToSlotById` 给剧情 NPC 塞的物品是展示道具。反例（灰色意志）：剧情永琳 H017 随身携带星之守护(I03D)+盖亚之盾(I05K)，但掉落表无任何 Boss 掉落这两件的记录——星之守护只能合成。
4. 合成类物品：找到脚本里的合成触发（条件=身上同时持有若干原料 → RemoveItem 原料 → UnitAddItemByIdSwapped 产物），引用行号说明配方，并指出原料各自的获取渠道（闸门 1 对每种原料再跑一遍）。
5. 通关/成就奖励：读完结局触发的完整函数体再下结论（灰色意志 Boss Rush 通关只给成就+评分，一件装备都不给）。

## 闸门 2：计数满量（防「截断数错个数」）

1. 统计「一共有几个」（Boss 数/配方数/掉落点数/指令数）时，必须消费 grep 的全部匹配行。
2. grep 工具单次上限 250 条：超限会明确报告，此时改窄 pattern 或按文件分片重查，直到全量到手。
3. 禁止 slice(0, N) 后直接报数；确需抽样时，答案里写「至少 N 个（抽样）」。
4. 反例（灰色意志）：Boss Rush 播报 grep 命中 61 条，只打印前 30 条就断言「8 个 Boss」，漏了排在 31224 行之后的八意永琳——实际 9 个。触发器在文件里的行号顺序不等于触发顺序，尾部的行同样可能是关键实体。

## 闸门 3：同名不同码（防「NPC 当 Boss」）

1. 内存/文本里看到单位名，必须先取它的 fourcc 码，对 `单位.tsv` 查阵营与类型再下身份结论：
   - 中立被动（PLAYER_NEUTRAL_PASSIVE）= 剧情 NPC，站桩、不可杀、不掉落。
   - 敌对槽位（常见 Player(8)）= 战斗实体。
2. Boss Rush / 挑战场常以另一个单位 ID 重生同名 Boss。反例（灰色意志）：剧情永琳 H017（中立被动、开局生成、随身剧情道具）vs Boss Rush 永琳 H010（敌对、Rush 中途生成、等级 34）。对玩家说「你看到的永琳」前，先确认说的是哪一个码。
3. 随机奖池（itempool 数组，如 `udg_SAO[]`）：描述成「打怪抽奖」——池子 N 选 1、抽取点 M 处；不要写成「XX 固定掉 XX」。灰色意志实例：SAO[5] 含涡流/嗜血/死之理等 13 种符文，Boss Rush+巢穴共 20 个抽取点。

## 闸门 4：实时内存的边界（防「脑补战斗」）

1. live 读数只列带物品单位：没有物品的战斗单位（大部分 Boss、小怪）不出现在列表里——列表里没有不等于场上没有。
2. 所有者分布的 P 槽计数变化（如 P8: 80→26）只说明敌方单位数变了，不构成「玩家正在打某 Boss」的证据；战斗状态需玩家口述或选中单位确认。
3. 游戏随时可能退出：每次回答前重探（AGENTS.d/live.md 强制），读到 war3 未运行就明说，不要用旧快照续答。
