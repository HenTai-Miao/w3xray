# GameXRay 0.9.0 地图直接查询与证据

本版维护 Windows x64，提供目录版 ZIP 和单文件 EXE。目录版完整解压后运行
`GameXRay 游戏档案透视器.exe`，保留旁边的 `_internal` 文件夹。
下列地图、战役、资料目录和文本解析均可离线使用，无需启动游戏或安装 Python。

## 直接查询地图或战役

从「数据工具 → 直接打开地图对象目录（离线）」选择 `.w3x`、`.w3m` 或 `.w3n`。
也可在「字段 / 对象 / 版本目录」内点击「选地图」。地图与知识包为互斥的来源；
「清空地图 / 包」恢复基础目录，外部 ID 与档案来源可以继续独立保留。

参考窗支持单位、英雄、物品、技能、增益、科技、可破坏物和装饰物，
按名称、四码、类别和全部字段查询，空关键词完整列出。Boolean 表达式沿用
`&&`、`||`、`%`、括号与精准词语法，完整字段值和来源扩展不会被截成摘要。
基础定义与地图记录分开列出；需要仅看地图时，在来源筛选输入地图文件名。

点击结果查看全部字段；「来源总览」展示原始地图路径、归档及成员 SHA256、
每个战役范围的对象数量、共享来源与完整诊断。战役共享定义展示一次，
章节保留各自覆盖与来源；同码不同类别、不同章节不会合并成同一对象。
脚本引用、文本/SLK 定义和明确二进制定义保留各自证据，不推断缺失的自定义状态或基础 ID。

读取在后台进行，可以取消。换来源、取消或关闭窗口后，旧查询、进度和导出结果
不能替代新选择。重新打开时恢复已选路径和既有窗口设置。

```powershell
& '.\GameXRay 游戏档案透视器.exe' reference --map 'D:\地图\示例.w3x' --kind objects --source '示例.w3x' --json
& '.\GameXRay 游戏档案透视器.exe' reference '攻击 && 火焰' --map 'D:\地图\示例.w3x' --category items --source '示例.w3x' --json
& '.\GameXRay 游戏档案透视器.exe' reference --map 'D:\地图\战役.w3n' --kind objects --limit all --export 'D:\报告\战役目录.json'
```

`--map` 与 `--pack` 互斥。`--limit` 默认 `0`，与 `all`、`全部` 一样表示全量；
明确给出正整数时选择完整记录，并报告遗漏数量。诊断和范围清单不受条目数量限制。
JSON 和文本导出保留所有被选中的记录、完整字段及来源台账。
导出不能覆盖源地图或其硬链接；可将独立报告保存在地图旁边或单独报告目录。

退出码 `0` 表示完整目录已建立，`2` 表示输入、来源变化或不完整读取。
部分来源的已确认记录仍可查看，来源诊断说明未确认范围；零匹配不等于地图没有该内容。

## 地图信息与完整原始证据

地图信息页补充了编辑器/游戏版本、数据集、加载屏、序章、雾、天气、水色、
镜头参数、玩家优先级、队伍标志、升级、科技及完整随机单位/物品表。
W3I 支持已经核实字段布局的格式 `18、23、24、25、26、27、28、31、32、33、39`。
这些数字是文件格式号，并非正在运行的游戏版本号。

地图信息和知识包共同保留截断、未知格式、未知脚本语言、异常数值和未消费尾部。
明确未知的脚本声明不会被主脚本后缀替换为另一种语言；独立 `.j` / `.lua` 来源仍按自身判断。
合法的可选表省略标记会明确显示，不把省略的表断言为空。

开启「基础」类目导出知识包时新增：

- `地图信息证据.json`：全部 W3I 字段、嵌套表、字节偏移、原始字节和结构化完整性状态。
- `地图字符串证据.json`：每份地图/战役 WTS 的全部记录、原始文本与字节、行号/字节范围、解析状态及诊断。

同一字符串 ID 的相同重复记录全部保留；不同内容或不完整声明产生冲突时，
不再任取一条作为名称。其他独立合法字符串仍正常解析，无法确认的 `TRIGSTR_...` 保留原引用。
地图与战役字符串分域读取，脚本原文和偏移保持不变。
证据 JSON 保留全部编码内容，包含无法解释的部分，且不输出无效 JSON 数值。

## 字段含义修正

修正了 17 个手工标签，包括攻击间隔、伤害骰子、伤害前摇、施法时间/后摇、
人口消耗、夜间视野、选择圈缩放、科技时间、物品模型和蓝色染色等。
这些修正共同用于对象详情、导出和参考目录。数据值与原始字段码保留，
旧缓存随语义版本换代，历史导出文件继续保留。

## 既有工作流与验收范围

本版保留地图知识包查询、存档分析、外部 ID、改键方案检查和已有只读实时探针。
操作见 [0.8.0 使用说明](usable-release-0.8.0.md)；实时读取继续要求对应的运行进程与已确认布局。

新增 Trainer 样本仅作为静态功能分析输入。分析与实现对应关系、完整计数和未知边界见
[本版审计](analysis/war3-trainer-2.1.21-adoption-2026-10-28.md)。
Windows 全量回归、质量检查、公开 GUI/CLI 及两种发行格式的实际结果，
以交付目录中绑定源码提交和产物 SHA256 的独立验收报告为准。
