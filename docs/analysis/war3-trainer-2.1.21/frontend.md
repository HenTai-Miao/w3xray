# v2.1.21 前端完整静态差异审计

本审计只读提取资源，不执行目标 EXE、DLL、JavaScript、HTML、字节码或地图脚本，不编辑产品源码。

采用词法作用域及绑定关系归一化，保留属性名、字符串/数值、模板原文、未绑定全局名和顶层引用身份；先形成候选，再单独比较完整规范 AST。新旧错误弹窗按静态职责人工对应，并明确保持“修改”状态。没有用压缩变量名或子串相似度直接声称等价。

141 项的具体结果：

- **137 项保留**：原桥接参数、动作分发、筛选、编辑、资源、技能、物品、存档、快捷键等在新版对应代码结构中保留。状态轮询的共享未完成 Promise、2500 ms 间隔和销毁清理另有逐语句证明。
- **1 项调用扩展**：原来声明但未使用的 `chooseDefinitionFile` 在地图目录选择入口开始调用。原包装未变。
- **3 项扩展**：导航由 13 页增加为 14 页；共用通知弹窗扩展完整原因展示与复制；翻译字典保留全部 379 个旧词条并新增 69 个。

地图目录之外的行为变化集中在**共用错误弹窗**：完整展示 `details` 中的 scope/file/message/impact，复制主消息、全部原因及日志路径，复制成功显示反馈；当 context 为 map_catalog 时提供“查看页面详情”并发出事件。该事件自身不切换当前导航页。弹窗由 640 px 扩为 860 px，将内容滚动与按钮区分开，操作按钮可换行。

地图目录新增了源路径/单文件选择、启动/取消及 400 ms 进度轮询、三类对象与来源/变更类型筛选、200 ms 关键词防抖、每页 100 条的分页、全字段详情、原值与不同 rawValue 分别展示、当前筛选或全部三类 CSV/JSON 导出、完整原因列表、复制和销毁清理。查询与详情具有序号失效判断；本报告没有把它提升为所有异步操作均无竞态的结论。详情复制文本没有包含单独显示的 rawValue，该边界完整保留。

新版直接桥接调用共 82 处；没有计算属性桥接调用、无法静态识别名称的网关调用或把桥接对象传给未知位置的引用。HTML 完整对比仅有 JS/CSS 指纹文件名变化；六份 pywebview JS 字节完全一致。除上述错误弹窗、地图目录、导航、版本默认值与翻译外，没有其他未分类的第一方顶层 AST 变化。

当前采纳流程已经具备完整来源/诊断展示、段落跳转、复制与导出，因此新增错误弹窗属于可复用交互证据，**不构成新的后端能力，也不要求本轮再增加一个全局弹窗**。

验证边界必须与结果一起保留：这是完整的静态声明与差异对账，不是运行语义证明。未运行浏览器、目标前端、游戏或目标本机桥接。Svelte 与 pywebview 第三方语义、调度/布局/剪贴板权限、动态间接行为与标识符反射均未证明。100 条为前端分页，不能据此推断全地图解析上限。

输入保护：19 个审计输入、899007 bytes 的 SHA-256、大小、修改时间、创建时间和 mode 前后一致；访问时间不在不变声明中。原始样本 EXE 的整体验证由父级容器审计负责。
