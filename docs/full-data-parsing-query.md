# 全量解析与知识包查询

地图数据、解析结果、报告和查询默认完整保留。容量取决于输入文件中真实存在的数据与机器资源；损坏声明、缺失 schema 和读写失败仍会明确记录，不能把未解析数据当成不存在。

数据读取没有默认字节配额；解压输出仍须符合格式声明，未压缩成员必须有足够的真实字节，图片也须有完整像素或压缩块。CASC/live 的原生分配按块进行，整体输入不设上限。嵌入调用和批处理参数可显式提供预算；资源不足、文件变化、损坏数据与不可读内存须明确报告。工作线程数量、缓存淘汰和路径安全校验保持各自职责。

当前地图的系统命令探测默认无输出容量和等待时限；嵌入调用可显式提供 `timeout_seconds` / `output_limit`，超出时返回具名诊断，不把截断内容解析成完整进程表。显式输出预算一旦超出立即终止命令，不必等生产方自行退出。近期缓存和日志的时间窗口仍用于判断线索是否属于当前会话，旧地图文件仍全部参与实时占用探测。

接收线程发生内存分配失败时也必须交付结果：系统探测返回 `resource_exhausted`，批处理结果接收或解码返回 `child_message_memory_error`，避免默认无时限时主线程永久等待已退出的接收线程。

日志只采用最新的「Opening map」记录；最新记录无法解析时不复用上一局的地图。相对路径在多个根目录都存在时保留全部候选，由证据解析器继续处理歧义，避免依靠目录顺序猜图。

批处理 CLI 默认无单图时限、无额外预留磁盘空间，仍使用可取消、可回收的隔离子进程。`--map-timeout-seconds`、`--max-memory-bytes`、`--minimum-free-bytes` 是显式选项；不再用地图大小乘以猜测膨胀倍数阻止启动，真实磁盘写入失败由原子发布路径报告并保留原结果。子进程结果也取消默认消息字节配额，传输故障会归因于读取失败。完整消息由接收线程读取，主循环持续检查取消与显式超时，半包或大消息传输不再阻塞取消。

## 查询接口

脚本函数与调用共用 `script_scopes.py` 的字符范围索引。支持 JASS 声明与 Lua 具名、赋值、嵌套、匿名函数、限定名称和方法调用；同一行内的多个函数按实际范围归属，不以行号猜测。范围与调用均用显式栈处理，不设函数数量或嵌套深度上限。函数声明、保留字、注释和普通字符串不会误记为具名调用；JASS 与 Lua 使用各自的保留字规则。

函数内部调用保留每个直接调用，参数中的具名调用也参与被调用计数。嵌套函数拥有独立的调用、对象码和字符串，父函数不重复领取其函数体证据。被调用次数以同来源的可定位绑定为准，递归不计作外部调用；同名定义或无法确定的绑定另列“歧义调用数”，不把数值当成运行时执行证明。未闭合函数仍保留范围并标注“未闭合”。

参数、对象码、字符串、变量、返回、条件、循环、局部声明和触发注册索引使用相同的函数范围。对象码按实际出现位置关联包含它的调用，摘要不会混入同一行相邻函数或其他语句的创建证据。`_G.` 全局限定名称保留原名，并识别已知原生 API 语义；其他限定名称不会被擅自改成原生 API。

索引新字段只追加到表尾：函数索引增加起始/结束偏移、父函数偏移、范围完整性与歧义调用数；调用参数索引增加调用偏移；对象码、字符串索引增加源码偏移。偏移均为原始文本的字符位置，函数结束偏移不包含该位置的字符。新调用偏移区分同一行完全相同的重复调用，脚本关系证据也携带该偏移，避免关系去重时丢掉真实重复。

函数摘要保存完整声明头；调用摘要保存完整调用表达式，每个有偏移的调用仅在首条参数记录中写一次，其余参数通过同一调用偏移关联；字符串摘要保存完整原始字面量，解码值与来源位置另列。没有裁剪字面量、参数或调用内容，也不再将一整行压缩脚本复制到每条证据中。知识包查询按表头读取摘要与偏移，兼容旧包的整行摘要，坐标与配方数量不会因新增字段或参数行重复而变多或变少。

`where` 与 `drop` 枚举全部命中的同名异码对象，同时保留目标侧、来源侧关系，并逐对象补充死亡、拾取和使用触发证据。已有关系行或另一个对象先命中都不会终止后续解析；关系表出现“掉落”也不遮住脚本中的其他掉落途径。脚本掉落标题仅标注脚本证据，不因进入补充路径就断言关系表没有记录。显式限量按坐标、关系行或独立脚本候选计数；所选对象的补充证据附在其首条记录中，保持完整，准确报告未显示记录数。文案线索先全量收集，再应用显式限量。

`refs` 按“分类 + 四码”分别显示完整引用分类，并保留来源文件、行号与函数。同名对象和不同分类的相同四码不会互相影响引用计数或升级判断；`--limit` 按对象计数，所选对象的全部引用与诊断共同保留。零消耗引用只描述当前可读索引，提供 `recipe` / `drop` 复核命令，不把静态缺失证据写成确定的升级终点。

`cmd` 与触发注册、脚本奖励共用 `script_trigger_bindings.py`，按来源文件、精确函数范围、句柄表达式和实际赋值位置区分触发实例。支持 JASS/Lua 的具名、赋值、局部、匿名条件与动作，以及 `_G.` 限定原生 API；同一行、变量重用、跨文件或不同局部作用域的同名处理器不会混并。数组下标完整解析，字符串键保留内部空白；重新赋值父表也会结束原触发实例。Lua 多变量赋值对每个左值建立新边界，表构造字段不误当成同名变量重赋值，构造表内函数的局部赋值仍独立解析。匿名回调和嵌套条件保留完整源码，不设注册数、正文长度和下标嵌套深度上限。

原生与 BJ 聊天注册使用平衡参数解析，支持跨行、深层玩家表达式和完整字符串；动态匹配参数保留原文并明确标注。动态句柄不跨调用猜测关联；动态数组下标只作为表达式级线索，显示运行时归属提示。动态或未定义回调保留表达式与原因，同名回调保留全部候选并显示歧义。死亡上下文只赋给当前实例内唯一、完整且无歧义的动作定义，不把其他触发器的事件、嵌套函数的注册或同名回调并进奖励证据；固定发放调用与死亡关联的推断等级分别保留。

触发注册 TSV 保持原九列顺序，表尾增加源码偏移、函数偏移、触发器赋值偏移、回调偏移、回调诊断、回调表达式和关联诊断。`cmd` 按完整注册条目限量，全部条件与动作正文保留空白、换行及字符串内容；同一回调重复注册时展示完整注册次数，函数体共用一次完整展示，不把重复注册静默合并成一次。缓存按完整文本及来源语言复用不可变范围和关联结构，不裁剪注册记录或候选。

Lua 的死亡、拾取、使用和丢弃触发通过 `script_trigger_acquisition.py` 生成结构化静态证据，`where` / `drop` 与攻略 drops / loot 共用该结果。按来源文件和字符范围关联具名、局部、匿名条件与动作；`if` / `elseif` / `else` 分支和循环以显式栈定位，不设行数、分支深度、处理器数或产出条数上限。else 保留排除条件原文，不继承先前分支的正向对象判定。同一触发器的多类事件分别展示，不只选择其中一类。

Lua 奖池由 `script_item_pools.py` 展开 `CreateItemPool`、`ItemPoolAddItemType`、`ItemPoolRemoveItemType`、`DestroyItemPool` 与 `PlaceRandomItem` 的静态定义和操作序列。`script_assignments.py` 统一提供完整赋值边界及句柄规范化，`script_control_ranges.py` 统一提供条件和循环范围；触发关联与奖池分析复用这些实现。奖池按同源源码内的变量声明、作用域和创建位置区分；数组键保留内部空白，父表替换会结束旧引用，同名局部变量及闭包各自定位。条件重建保留多个定义候选，不把成员混成一个确定池。跨函数修改或闭包重赋值的时序不猜测，保留诊断与全部相关登记。

`where` / `drop` 可从死亡单位、使用/拾取媒介或任一活动候选成员反查奖池；没有对象表记录的四码也会检查原始脚本。攻略同源输出全部成员、权重、创建位置和操作历史。确定的同作用域序列按放置位置生成快照：移除后的物品不当作活动成员，销毁后不列有效产出，重建后不借用旧池，后续操作不改写前一次抽取的证据。静态空池仍显示快照及历史，未定位创建、动态索引、动态成员和动态移除均明确提示。

固定十进制源码权重以输入位数决定 Decimal 精度，避免默认精度舍入长字面量；显示“原文权重 / 原文总权重”，不把源码比例宣称为运行时必得概率。动态、算术、负权重或超出可验证浮点范围的数值保留完整原文，不伪造总权重。0 物品ID也保留并计入源码权重，同时提示可能抽不到有效物品。同一物品重复登记时保留每一条，因覆盖/累计语义未确定而停止推导总权重。条件或循环登记保留候选与次数不确定性，不折成单次固定登记。原生接口及其 0 ID 行为核对 [jassdoc 的 item-pool 定义](https://github.com/lep/jassdoc/blob/master/common.j#L19978)。

奖池定义、成员、权重与操作条数均不设默认上限。赋值历史和操作位置按索引定位，不为每次放置扫描整段历史；同一状态的快照共用不可变成员与操作记录，查询通过成员集合定位，展示只展开一次奖池目录，每次 `PlaceRandomItem` 仍各自保留原文及位置。成员表和放置记录都完整保留，显式 `--limit` 不切断所选证据块的成员清单。

识别 `CreateItem` / `CreateItemLoc` / `BlzCreateItemWithSkin`、`UnitAddItemById` / `UnitAddItemByIdSwapped` / `UnitAddItemToSlotById`，商店上架 `AddItemToStock` / `AddItemToStockBJ` 与 `PlaceRandomItem` 调用。四码、FourCC、十六进制和十进制对象码按类型参数位置读取，`_G.` 限定原生调用保留来源；类型比较支持正反两侧，带算术的比较不误认成四码等值。同一行的相同调用按各自偏移保留。动态物品码不猜测，未解析奖池成员时保留奖池调用并明确提示，未闭合函数和回调歧义仍展示诊断。

条件与同处理器此前的随机调用保留完整原文并通过编号关联，公共文本只展开一次，避免按产出数反复复制长摘要。攻略按完整 Lua 证据块合并，不再逐行去重，因此同一行的相同调用、不同位置的重复产出和各块自身的条件关联都保留。输出标注静态线索，不把上架、随机候选、条件相关对象或未注册的处理函数宣称为必得掉落。原有 JASS 奖池、YDWE 和数组池证据继续使用既有解析；跨文件的 JASS 条件/动作仍可关联，Lua 显示文本不会进入 JASS 处理器搜索。Lua 语法与原生参数位置分别核对 [Lua 官方函数定义规范](https://www.lua.org/manual/5.4/manual.html#3.4.11) 和 [jassdoc 的 common.j 定义与示例](https://github.com/lep/jassdoc/blob/master/common.j)。

`affixes` 保留同名但倍率或属性不同的定义，按实际定义条数限量；一行特效与两行公式不再影响计数。`registered` 同时搜索消息名与 JSON 全文，使用 Unicode 大小写折叠，兼容“序号”与“记录数”表头及无表头旧包；首条真实记录不再丢失。消息名总览与正文查询均披露实际余量，正文不截断。`quest` 也先收集全部匹配，再按真实条数限量，恰好达到上限时不误报截断。

重复使用的死亡、单位随机掉落和物品触发结构按完整脚本内容缓存为不可变记录。缓存只减少重复解析，不裁剪对象或证据；同尺寸、同 mtime 的脚本内容变化仍触发重新解析。

合成识别按完整调用顺序解析，不再要求至少两件材料；单材料升级、同码重铸、同一行多次结算和跨行调用均保留。消耗与发放按各函数的实际物品参数位置解析，不会把单位参数中的对象码或被移除的嵌套 `CreateItem` 当作成品。Lua 单引号 `FourCC` 每次出现只计一份材料，独立重复消耗照实累计；具名与匿名函数隔离材料状态，保留来源、函数、行号、偏移及完整消耗/产出证据。仅查询物品类型而未移除的调用不算消耗。条件、循环与动态消耗保留“可推断”及原因，关系报告、`recipe` 与 `synth` 查询同步展示。

`recipe` 与 `synth` 直接读取所有可读来源的 `YDWENewItemsFormula`，并兼容旧调用摘要与完整参数索引；多行调用即使摘要只有首行，仍可按参数序号还原。支持 JASS 四码、Lua `FourCC`、长字符串、十六进制和十进制码，数量使用精确整数，不经过浮点转换，也不展开成重复材料列表。相同材料合并数量，零或负数占位项跳过，正数 `ches` 作为真实奶酪材料保留。原文与索引按较大出现次数合并，配方查询去除镜像重复，同时保留同一产物、同一材料但不同数量的配方。变量或不完整公式不猜测为完整配方。

`analysis_script_sources` 同时提供来源名、完整文本与语言上下文。WCT 自定义代码采用地图声明的 `script_type`；无声明时仅在主脚本语言唯一时继承，不把 `.txt` 直接认成 JASS。未知来源保持未知，`脚本清单.txt` 逐项显示语言。工具生成的 WCT 段落标题适配 Lua 注释，字符长度与行号保持不变，原始 `MapData.scripts` 不被改写。

知识包坐标查询完整读取 `.j`、`.lua` 和可读 `.txt`，结合 `地图信息.txt` 的语言声明解析 WCT；旧调用参数索引也使用同一判定。机制报告逐来源分析后合并，不再将多种语言直接拼接，也不会把注释或显示文本中的 BJ 函数名认成地图机制。

`item`、`tech`、`price`、`shop`、`recipe` 的显式 `--limit` 按实际对象、商店或配方计数，完整保留所选条目的说明、逐级效果和来源证据；不再以输出行数乘以 3/8/12 猜测对象数量。同一商店的货架、制造与出售证据共同占一个商店名额；配方先合并关系表与脚本索引，再限量，相同产物的不同配方分别计数，材料名称也支持 Unicode casefold。只有确实省略结果时才报告准确余量，默认或 `--limit 0` 始终全量。物品与价格查询兼容缺少说明列的旧包，名称匹配使用 Unicode casefold。

脚本索引与静态坐标解析共用按语言处理的词法视图，保持字符偏移和行号。Lua 长字符串、单引号字符串和长注释中的示例不会冒充可执行调用；Lua `//` 保留为整除，JASS 表达式中的连续负号也不会被当作 Lua 注释。调用参数支持括号、索引、表构造和匿名函数块，参数间注释里的逗号或括号不会造成错误拆分；已准备的脚本视图可重复使用，避免逐次调用重扫整份脚本。

`FourCC` 与其参数之间不设 24 字符回看窗口，支持长空白、注释及 Lua 长字符串形式。Lua 普通四字字符串保留为文本，JASS 四字对象码与真正的 `FourCC` 操作数保留为对象证据；码里的括号也不会提前结束调用。多行 Lua 字符串以完整条目进入字符串索引，未闭合或多个相邻字面量不会冒充一个字符串。存档键的深层 `StringHash` 以迭代方式解析，直接嵌套链避免重复扫描。

`heroes`、`units`、`skills`、`buffs` 共用完整清单读取，兼容只有五个必需列的旧知识包；缺少来源列时明确显示「来源未记录」。四个入口均可按名称、ID 或说明查询，完整保留说明文本。默认全量列出，显式 `--limit` 按对象数缩减并报告精确剩余条数。

`search` 完整搜索八类对象表的名称、四码、数值 ID、基础 ID、说明、英文名及扩展文本。可用 `物品:`、`单位:` 等中文分类或 `items:`、`units:` 等英文前缀缩小范围；分类后不写词会完整列出该表。支持 `&&`、`||`、括号、`%` 通配符和 `="精准词"`。普通词使用 Unicode 大小写折叠，精准词保留大小写；每个词在单个字段内匹配，AND 条件可分别命中不同字段，前后缀通配不会被额外拼接的对象 ID 干扰。说明命中时输出完整证据文本。长表达式使用一次遍历摊平与迭代求值，AND 首次失败后短路，不设置词数或括号深度上限。

攻略和标注小地图保留同一码的全部不同坐标，合并预放置与全部 JASS/Lua 脚本的镜像坐标；静态脚本位置代表创建位置证据，不能据此断言单位当前在场。实例专属掉落仅附在对应坐标，可破坏物掉落同样带位置。归档预放置数据损坏会明确报错，避免发布不完整点位。小地图图例按完整名称和精确坐标自动扩宽，范围外点位保留在图例并标注；网格以地图较长边计算，狭长地图不再因短边决定间隔而生成过量网格。

坐标和对象浮点字段在导出、GUI、攻略与 live 查询模板中保留可往返的完整精度，不再限制为 4/6/9 位有效数字或先取整。`where` 与 `near` 共用表头驱动的预放置读取：单位、地面物品、装饰物均可按名称或四码定位，物品分类以对象表为依据。

`near` 的 JSON 条目直接来自空间查询数据，坐标和距离不再从展示文本重新提取。每条增加 `positions`，保留聚合组内每个实例的完整 `[x,y]`；`count` 与其长度相等，`x/y` 是组中心，`dist` 是该中心的完整浮点距离。装饰物使用邻近网格分组，维持原先按种类、按种子半径聚合的语义，避免每组都重扫全部剩余点。显式 `--limit` 同时约束半径外提示并报告剩余条数。

静态坐标和矩形解析支持深层括号、长一元运算链、十六进制常量与运算符优先级；JASS 与 Lua 的 `gg_rct_* = Rect(...)` 都参与区域反查，注释和字符串中的示例不采纳。数字对象码按原始四字节还原，保留非 ASCII 字节。动态函数、变量和非法或非有限数值仍不求值。

查询窗、收藏、live 探针和攻略窗口通过 `query_coordinates.py` 共用坐标识别：支持科学计数法、带嵌套物品栏的 `selected` / `selected_unit` JSON、`near x y` 模板和 `@(x,y)` 标注。对象码、所有者号和聚合数量不会误作坐标；有多组不同坐标时拒绝猜测，需精确选中一行或一个对象。剪贴板半径也保留完整数值。

```powershell
uv run main.py pack-query "<知识包目录>" where I001
uv run main.py pack-query "<知识包目录>" search "物品:火焰 && 攻击"
uv run main.py pack-query "<知识包目录>" search 'items:="Flame Sword" || 烈焰%'
uv run main.py pack-query "<知识包目录>" near 100 -200 500 --kind 物品 --json
uv run main.py pack-query "<战役知识包目录>" near 100 -200 500 --json
uv run main.py pack-query "<知识包目录>" again --json
```

不传 `--limit` 或传 `--limit 0` 时完整输出。显式 `--limit N` 是调用者主动缩减，结果会提示截断。战役枚举不依赖掉落关系表存在，仅包含对象表或脚本的子图同样参与查询。

`--json` 的查询结果标准输出是一个可直接 `json.loads` 的 JSON 文档；诊断和耗时走标准错误。单图保留 `section`、`lines`，并增加 `pack`、`command`、`query`、`exit_code`、`warnings`。战役增加 `sections`，每段带自身知识包路径；`near` 同时在总结果与各段提供 `entries`，总结果条目带 `section` 标明任务关。未命中与坐标参数错误也使用同一 JSON 结构；命令行选项自身的解析错误沿用 CLI 错误出口。

`gametool.pack_query_cli.execute_pack_query` 返回 `PackQueryResult`，不修改标准输出和标准错误；CLI 负责打印，GUI 直接消费返回值。所有查询使用一致的成功判定、最近查询记忆和战役遍历。`again` 重跑原命令，包括逐关查询，同时保留原始查询记忆。

表格缓存以纳秒 mtime、大小和全文件 SHA-256 共同失效。一次查询内每张表仅做一次校验与读取，下一次查询重新验证；同尺寸、同 mtime、仅尾部变动也会被识别。暂时无权限或被占用的文件在后续查询重新尝试，读取失败不永久污染当前 GUI 进程。

`tech` 完整列出每个等级的费用与对象字段中存在的各级效果；取消只展示 1/5/满级费用及首末级效果的采样。满级累计费用以等差数列计算，避免为汇总再次遍历全部等级。

坐标解析覆盖全部 `.j`、`.lua` 脚本及无原文旧包的调用参数索引，静态识别 `CreateUnit`、`CreateItem`、`CreateUnitAtLoc`、`CreateItemLoc`、`BlzCreateUnitWithSkin`、`BlzCreateItemWithSkin`。支持嵌套的 `Player(...)`、带空格的一元负号、科学计数法、JASS 四码、Lua `FourCC`、十六进制和十进制整数码，以及由纯数字组成的加减乘除/余数/幂、Lua 整除与 `Location(x,y)`。按来源文件保留语言语义，Lua 的 `//` 不再当作 JASS 注释。算术以显式栈解析，不受 Python AST 的括号深度与递归限制，不执行脚本；动态变量/函数/属性不求值，注释和字符串中的示例调用不采纳。同一调用参数的多行索引与原文按出现次数去重，实际重复创建仍保留。

脚本坐标还覆盖 `CreateCorpse` 以及 `CreateDestructable`、`CreateDestructableZ`、`CreateDeadDestructable`、`CreateDeadDestructableZ`。`where <名字或四码>` 给出可破坏物坐标；`near` 将其列为「脚本可破坏物」，关联对象表名称和关系表掉落，提供同样的 JSON 坐标条目。`--kind 装饰` 和 `--kind 脚本` 均可筛选；脚本物品和可破坏物在显式 `--limit` 时报告精确未显示条数，默认全量。

guide 缓存语义版本为 `guide-v26`，live 自动知识包版本为 `live-pack-v16`；批处理提取修订为 19。Lua 获取途径和触发产出修复影响攻略与查询内容，旧版本不再复用；客户端基础对象快照语义不变。现存手动知识包要获得新增的范围、偏移和触发诊断信息，需要重新导出；查询层继续兼容旧索引，保留原始可读 Lua 脚本的知识包可直接使用增强后的 `where` / `drop` 查询。

客户端基础对象快照同步使用 `gamexray-client-snapshot-v2`，旧字段精度的 v1 快照不再复用；缓存重新生成时保留完整对象浮点文本。

辅助函数链也参与获取途径分析：`where`、`drop` 和攻略的掉落、开箱段沿当前源码中可定位的 JASS/Lua 函数展开，保留每个调用位置、分支、函数原文位置与字面量实参。`Grant(FourCC('I001'))` → `CreateItem(id, …)` 会将 `id` 关联到 `I001`，原始调用语句仍完整展示。条件辅助函数中的字面量实参同样提供单位/物品选择证据。`cmd` 在完整回调正文后显示可定位的辅助函数正文与调用图。

调用分析没有固定层数或路径条数上限。相同函数及相同静态实参共用节点，所有调用位置分别保留；递归按有限上下文图记录并提示循环，菱形调用关系不枚举指数增长的完整路径。局部变量、闭包、普通赋值、并行赋值、函数别名、方法调用与块作用域共用解析；重赋值、循环变量、动态实参、未确定的函数绑定保留诊断。分支与候选调用关系属于静态线索，不能据此承诺实际执行次数或必定获得物品；外部脚本、动态调度和加密代码仍须额外证据。

返回值索引通过 `script_returns.py` 收集当前源码中每一处 `return`，包括同行分支、跨行表达式、长字符串、嵌套函数和多返回值。没有每行一条、表达式长度或括号层数上限。原有十列保持顺序，末尾增加「偏移、结束行、结束偏移、诊断」四列；表达式中的全部返回值仍完整保留。

`script_values.py` 用显式任务栈追踪可确认的标量返回值：常量对象码、字符串、数值、实参、局部赋值、函数别名、方法和转发 getter 都可参与 `where` / `drop` 与攻略的产出分析，`FourCC(Name())` 也支持。源码函数名、返回原文、行号、偏移及实参作为证据显示；条件中的对象码 getter 同样解析。一个函数有多处返回、返回位于条件/循环、绑定不唯一或出现递归环时保留诊断，原始返回索引仍满量。普通字符串不冒充整数对象码。

求值缓存以作用域、参数和绑定状态区间区分：赋值、局部声明及块边界形成独立区间，同一区间的嵌套表达式共用结果。依赖与证据共享节点，没有固定调用深度或候选条数闸门。Lua 标量位置只采首返回值，末参数按多返回值规则展开完整已知列表，未确定的长度/值以动态尾部保留诊断；完整表达式保留在索引和证据中，语义参考 [Lua 官方多返回值说明](https://www.lua.org/manual/5.4/manual.html#3.4.12)。分析始终只读，不执行地图脚本。

Lua 多返回值完整参与获取途径分析：函数调用、返回列表、并行赋值和直接 `...` 透传共用 `StaticValues`。仅末表达式展开多结果，非末位置和括号表达式取一个值；固定形参数按语言规则丢弃多余实参或补 nil，变长函数保留全部已知额外实参。没有返回值条数、变长参数数量或并行左值数量上限。`local a,b=Ids()` 可确认第二个值，`UnitAddItemById(Args())` 即使物品参数位于展开后的第二位也会保留；原始调用和返回列表不改写。

未知长度的返回保留已知前缀和动态尾部，不能把未知位置当作 nil。并行赋值全部 RHS 按赋值前的绑定状态解析。递归变长上下文若持续增长，仅将无法静态穷举的尾部归为未确定，保留源码固定前缀、调用位置与诊断；非递归长列表和逐步缩短的已知列表完整解析。JASS 保持单返回值语义。

`script_lua_builtins.py` 将 `select` 和 `table.unpack` 接入同一值列表与证据图。`select` 的正索引完整保留后续值，负索引从末尾计数，`#` 计数包含 nil；未知尾部不被误算为固定长度。标准库与别名按源码绑定解析，局部同名函数和成员重定义按实际函数处理；父表在成员定义后被替换时，不沿用旧成员。别名在替换前捕获的函数仍保留原绑定。

`table.unpack({…})` 仅对本次调用中新建、没有命名/索引字段的数组静态展开。逗号、分号、末尾分隔符、注释、字符串和匿名函数体保持 Lua 字段边界；末字段展开所有已知返回值。源码编码元素没有条数上限，显式范围可保留其中的 nil 空洞。默认范围依赖 `#`，有空洞或未知元素时不能保证唯一长度，必须保留诊断。可变表、动态范围与超出源码编码索引的范围明确报告分析边界，不按经验数量截断，也不为巨大虚拟 nil 区间分配内存。此处边界不表示 Lua 禁止访问这些索引。语义依据 [Lua select](https://www.lua.org/manual/5.4/manual.html#pdf-select)、[Lua table.unpack](https://www.lua.org/manual/5.4/manual.html#pdf-table.unpack) 和 [数组长度规则](https://www.lua.org/manual/5.4/manual.html#3.4.7)。
