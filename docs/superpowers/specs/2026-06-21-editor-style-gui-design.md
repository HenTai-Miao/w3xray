# Editor-Style GUI Redesign

## Goal

将现有 GUI 从早期分页浏览器，整理成更接近 Warcraft III World Editor 的只读分析工作台。

## Direction

用户选择“偏编辑器风格”。布局应强调地图/战役导航、对象编辑、触发/脚本检查、场景结构、资源与兼容体检，而不是营销式页面或单一报告页。

## Information Architecture

- 顶部工具栏：保留打开地图、导出文件、导出脚本、导出 ID 列表，文案改成更像工具栏。
- 模式切换：保留对战图/战役图切换。
- 工作区标签：
  - 总览：当前地图的对象数量、脚本/指令/合成、预放置、风险摘要。
  - 对象编辑器：保留单位/物品/技能/科技并列浏览和右侧详情。
  - 地图信息：保留 war3map.w3i / war3campaign.w3f 只读信息。
  - 场景放置：保留预放置单位、装饰物、可破坏物。
  - 触发指令：保留隐藏聊天指令。
  - 合成配方：保留识别出的物品合成。
  - 孤立对象：保留引用分析结果。
  - 分析报告：新增统一报告，汇总审计、脚本诊断、崩溃风险、秘籍残留、命令冲突、资源、兼容、地形、SLK、游戏常数。

## Architecture

新增 GUI 报告模块承载纯数据整理逻辑，避免继续把所有功能写进 `w3xtool/gui.py`。GUI 主类只负责创建文本框和刷新文本；报告内容由独立模块生成，方便单元测试。

## Testing

- 新增纯函数测试，验证空地图、风险地图和对象统计会形成总览/报告块。
- 新增 GUI 测试，验证新布局标签存在，加载地图后总览和分析报告会刷新。
- 保留现有 GUI 测试，确保原对象浏览、预放置、指令、配方、复制、战役导航不回退。
