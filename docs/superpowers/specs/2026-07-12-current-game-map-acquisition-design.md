# 当前游戏地图获取设计

## 目标

为 W3XRAY 增加“获取当前地图”能力：从操作系统可见的进程与磁盘证据定位 Warcraft III 正在使用的 `.w3x/.w3m/.w3n`，复制到受控临时快照后复用现有只读解析链。GUI 和 CLI 使用同一定位器。

## 安全边界

- 只读取进程列表、命令行、打开文件路径、`.wgc` 配置和地图/缓存文件元数据。
- 不读取游戏内存，不打开 `Game.dll`，不注入 DLL，不调用地图或平台代码，不申请提权。
- 不把“最近修改的地图”等同于“当前地图”。只有与 Warcraft 游戏进程直接关联的唯一文件才自动打开。
- 地图源文件永不修改；定位后复制到权限受控的临时目录，解析快照。
- 自定义加密若只在游戏内存中解密，本功能不能恢复；快照只能保留磁盘上已有的字节并交给现有兼容解析器。

## 证据与决策

证据按可靠性分两层：

1. 直接证据：Warcraft 游戏 PID 打开的地图文件，或该 PID 命令行中明确存在且可解析的地图路径。
2. 提示证据：游戏运行期间最近写入的地图/平台缓存，以及最近写入 `.wgc` 中引用的现存地图。

纯函数解析器返回五种状态：

- `FOUND`：唯一直接证据，可以自动建立快照。
- `AMBIGUOUS`：多个直接地图，例如多个游戏实例或战役容器与子图并存；不猜测。
- `SUGGESTED`：只有提示证据；GUI 必须让用户确认，CLI 必须显式传 `--accept-suggestion`。
- `NOT_FOUND`：未发现游戏进程或没有候选。
- `UNAVAILABLE`：游戏存在，但当前平台的直接文件探针不可用且没有提示。

World Editor、Battle.net、启动器和下载客户端不算游戏进程。相同规范路径上的多个证据会合并，多个 PID 打开同一地图仍视为唯一地图。

## 平台适配

- macOS：`/bin/ps` 识别 Warcraft/Wine/CrossOver PID，`/usr/sbin/lsof` 只查询最多 8 个 PID。
- Linux/Wine：读取 `/proc/<pid>/fd`，不可用时回退到 `lsof`。
- Windows：PowerShell/CIM 读取进程名和命令行，支持显式地图参数；本版不实现未经真机验证的句柄枚举。
- 所有外部命令使用参数数组、`shell=False`、固定超时和输出上限。拒绝权限、工具缺失和超时转为诊断状态。

## 有界磁盘扫描

扫描范围只包含用户最近选择的地图目录和已知 Warcraft/CrossOver/Wine 地图目录，最多 8 个根、5 层、5000 个目录项。提示窗口为 15 分钟；只有检测到游戏进程时才产生提示。候选必须是现存 regular file，扩展名必须是 `.w3x/.w3m/.w3n`，符号链接、FIFO、设备和目录均拒绝。

`.wgc` 只作为提示：解析 `map_path` 后在配置文件目录、地图根和其 Warcraft 父目录中解析相对路径。陈旧 `.wgc` 不参与选择，也绝不覆盖直接证据。

## 快照与生命周期

快照创建前后比较源文件设备号、inode、大小和纳秒 mtime；复制期间发生变化则删除快照并报告失败。快照位于系统临时目录下的私有唯一子目录，文件名固定为 `current` 加原扩展名，并计算 SHA-256。

CLI 在 `run_cli` 返回后删除快照。GUI 保存本会话创建的快照，确保延迟报告可以重开 `PathArchiveSource`；应用退出并关闭 resolver 后统一删除。异常退出残留由下次运行的有界陈旧清理回收。

## 产品入口

- GUI 顶栏在“打开地图 / 战役”旁增加“获取当前地图”。探测在线程中完成，通过 Tk 轮询队列回到主线程；直接结果自动加载，提示结果显示来源和路径后确认，歧义和未找到只展示说明。
- CLI 增加 `main.py current`，支持重复 `--root`、`--accept-suggestion`，并转发现有 `--listfile/--game-data/--author-bundle/--pack`。
- 两个入口最终都只调用现有 `_start_path_load(path)` 或 `run_cli(CliOptions(...))`，不创建第二套地图解析器。

## 验收

- 一个游戏 PID 直接打开一张地图时得到 `FOUND`；中文和空格路径保持精确。
- 编辑器/启动器打开地图不能触发自动选择。
- 两个直接地图得到 `AMBIGUOUS`，不得按 mtime 猜测。
- 游戏不存在时，最近地图和陈旧 `.wgc` 不产生自动结果。
- 探针超时/拒绝/缺失有界失败，GUI 不阻塞。
- 快照字节与源文件 SHA-256 一致，源地图的大小、mtime 和 SHA-256 不变。
- 手动打开、现有 CLI、全量测试和真实地图回归保持通过。
