# Map Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only map audit report that turns parsed map data into actionable warnings and CLI summary lines.

**Architecture:** Keep the analysis in a new small module, so the oversized API loader does not gain more responsibility. The audit module consumes `MapData` after parsing and returns typed immutable findings; CLI rendering stays in `main.py`.

**Tech Stack:** Python 3.14, dataclasses, pytest, existing `MapData` / `GameObject` structures.

---
